# 📦 Supply Chain Analytics Dashboard

## 📌 Project Overview
This Excel-based Supply Chain Analytics Dashboard provides insights into supplier performance, inventory management, order fulfillment, product damages, and return analysis. The dashboard helps monitor key supply chain metrics and supports data-driven decision-making.

---

## 🎯 Objectives
- Evaluate supplier performance.
- Monitor inventory and fulfillment efficiency.
- Analyze product damages and returns.
- Identify high-performing and underperforming suppliers.
- Support supply chain optimization.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

---

## 📊 Dashboard Features

### Supply Chain Executive Dashboard
- Inventory Analysis
- Order Fulfillment Performance
- Damage & Return Analysis
- Supplier Comparison
- Business KPIs
- Interactive Slicers

  ### Supplier Performance Dashboard
- Supplier Fill Rate
- On-Time Delivery Rate
- Product Damage Rate
- Return Rate
- Supplier Rating
- Interactive Filters

---

## 📈 Key Insights
- Compared supplier performance across multiple KPIs.
- Identified suppliers with higher product damage and return rates.
- Evaluated order fulfillment and delivery performance.
- Highlighted opportunities to improve inventory management and supplier efficiency.
